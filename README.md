# 🛡️ HeatShield Pakistan — UN SDG 13 Community Action Platform

**HeatShield Pakistan** is a responsive, interactive civic-tech web platform built for our university **Community Engagement** course project. It addresses **UN Sustainable Development Goal 13 (Climate Action)** alongside **SDG 3 (Good Health & Well-Being)** and **SDG 11 (Sustainable Cities & Communities)** by tackling extreme heatwave risks across Pakistan.

---

## 🌟 Key Features

1. **Emergency SOS Modal (`1122`):** One-tap access to Pakistan's emergency helplines (Rescue 1122, Edhi 115, Chippa 1020, NDMA 1700) and immediate heatstroke response steps.
2. **Live City Heatwave Monitor:** Interactive city switcher (`Lahore`, `Karachi`, `Multan`, `Jacobabad`, `Islamabad`) showing temperature, humidity, feels-like Heat Index, and NDMA advisory levels.
3. **Scientific Heat Index & Risk Calculator:** Uses the official **NOAA Rothfusz regression equation** to calculate real-time heat stress risk and recommend hourly water/ORS intake based on user exposure level.
4. **Medical First-Aid & WHO ORS Guide:** Side-by-side comparison of **Heat Exhaustion vs. Heatstroke**, a 5-step rapid cooling protocol, and the home-prepared WHO Oral Rehydration Salts (ORS) formula.
5. **Community Engagement Roadmap:** Tracks on-ground awareness drives, hydration camps, and school workshops with a built-in **Proposal Customizer** (`localStorage` enabled).
6. **UN SDG 13 Digital Pledge Certificate:** Generates and downloads a high-resolution **PNG certificate** directly in the browser using the HTML5 Canvas API.

---

## 🛠️ Tech Stack & How It Was Built

* **Structure & Semantics:** HTML5 (Single-Page Application architecture for fast loading on low-bandwidth mobile networks)
* **Styling & UI Design:** Tailwind CSS, Custom CSS3 Variables, Responsive Flexbox/Grid Layouts, and Google Fonts (`Plus Jakarta Sans` & `JetBrains Mono`)
* **Interactive Logic:** Vanilla JavaScript (ES6+) — zero heavy framework bloat
* **Graphics & Export:** HTML5 `<canvas>` API for client-side PNG certificate generation and Lucide vector icons
* **Hosting & Deployment:** GitHub Pages with HTTPS encryption
